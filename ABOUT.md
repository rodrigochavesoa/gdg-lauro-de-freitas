# GDGJobs — Visão geral do projeto

GDGJobs é um projeto de portfólio e aprendizado que explora uma experiência comunitária para descoberta de oportunidades em tecnologia. Não é o produto oficial do GDG Lauro de Freitas.

## Produto

A jornada principal reúne descoberta de vagas, leitura de detalhes, candidatura e acompanhamento. Candidatos também podem compartilhar o perfil na comunidade e ativar recomendações explicáveis no catálogo. A equipe do projeto usa ferramentas administrativas para organizar conteúdo e trabalho editorial.

## Funcionalidades

- Catálogo de oportunidades com busca e filtros.
- Recomendações determinísticas com motivos de compatibilidade visíveis.
- Conta de candidato, perfil e acompanhamento de candidaturas.
- Comunidade de perfis profissionais com compartilhamento opcional.
- Ferramentas para revisão editorial de vagas.
- Interface responsiva, com temas claro e escuro.

## Stack principal

- React e Vite para a aplicação web.
- JavaScript e CSS para interface e estilos.
- Supabase para serviços de aplicação.
- Vercel para hospedagem web.
- pnpm, ESLint e Vitest para desenvolvimento e qualidade.

## Estrutura de código

- `src/app/` contém a composição e navegação da aplicação.
- `src/features/` organiza as áreas do produto.
- `src/shared/` e `src/lib/` mantêm componentes e utilitários compartilhados.
- `public/` contém assets servidos pela aplicação.
