# Roadmap de System Design (modelo)

Copie o conteúdo operacional para `docs-local/system-design-roadmap.md` na cópia local do mantenedor. A versão do squad **não** é versionada.

## O que o modelo cobre

- decisão central: conceitos como critérios, não lista obrigatória de tecnologias;
- arquitetura monólito gerenciada (sem troca de stack);
- quatro perguntas de projeto (carga, dados, falhas, operação);
- sete camadas de sequenciamento sobre sprints existentes;
- governança para nova tecnologia (6 critérios);
- riscos de overengineering.
