# GDGJobs

Plataforma de vagas tech curada pela comunidade GDG. O protótipo atual é um frontend React/Vite com dados simulados.

## Contribuição

Branch + PR para `main`; commits em [Conventional Commits](https://www.conventionalcommits.org/pt-br/v1.0.0-beta.4/). Guia: [`docs/contributing.md`](docs/contributing.md).

## Qualidade local

Use **PowerShell (`pwsh`)** no Windows. Não use WSL para install, lint, testes ou build.

```powershell
pnpm install
pnpm lint
pnpm test
pnpm run build
```

Detalhes do pipeline: [`docs/quality-ci.md`](docs/quality-ci.md). Fluxo Git e commits: [`docs/contributing.md`](docs/contributing.md).
