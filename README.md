# GDGJobs

Plataforma de vagas tech curada pela comunidade GDG. O protótipo atual é um frontend React/Vite com dados simulados.

## Qualidade local

Use **PowerShell (`pwsh`)** no Windows. Não use WSL para install, lint, testes ou build.

```powershell
pnpm install
pnpm lint
pnpm test
pnpm run build
```

Detalhes do pipeline: [`docs/quality-ci.md`](docs/quality-ci.md).
